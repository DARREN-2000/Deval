deval scan . -f sarif -o deval.sarif

# Scan the current directory, read-only, as a non-root user

  scan . -f markdown

# Pin a version for reproducible pipelines
docker run --rm -v "$PWD:/repo:ro" ghcr.io/darren-2000/deval:0.6.0
# .github/workflows/deval.yml
name: deval
on: [push, pull_request]

jobs:
  standards:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      security-events: write
    steps:
      - uses: actions/checkout@v4
      - uses: DARREN-2000/deval@v1
        id: deval
        with:
          path: .
          min-score: '80'
          upload-sarif: 'true'
      - uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: report.sarif

      # Outputs: score, grade, passed
      - run: echo "Scored ${{ steps.deval.outputs.score }}"
# Fail the build below a score, or on any error-level finding
deval scan . --min-score 80 --fail-on error

# Adopt gradually: freeze today's findings, block only new ones
deval baseline .
deval scan . --baseline .deval/baseline.json

# Check config and tool readiness before you rely on it
deval doctor .

What makes it different

Deterministic, not probabilistic

No model sits in the loop. The same commit always produces the same score, so it can gate a build without flaking.

One score from many tools

Findings from Ruff, Semgrep, Trivy, and Gitleaks are normalised, de-duplicated, and folded into a single number.

Every rule explains itself

Each rule carries a stable DV code with problem, rationale, example, and fix. deval explain prints all of it.

Standards you can layer

Global → Recommended → Domain → Organization → Repository. A repo override always wins; nothing is applied silently.

Rules are just functions

Write a rule with a decorator and drop it in a plugin folder. No subclassing, no framework to learn.

Adoptable on day one

Baselines freeze existing debt so a large codebase can enforce standards on new work without a rewrite.

13 engineering dimensions

Each dimension is scored independently, then weighted into the overall figure. Dimensions with no evidence are excluded rather than counted as perfect.
